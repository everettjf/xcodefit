# Native app screenshots

Real XcodeFit 1.0.7 Debug captures, using `--ui-fixture` and isolated disposable folders, taken on 2026-10-20. The interface uses native system surfaces and bamboo-green accents. The operating system's screen-sharing indicator may appear in the title bar; it is not an XcodeFit control.

- `overview-light.jpg` / `overview-dark.jpg`: refreshed compact 2200×1464 captures, taken in the same window with only appearance changed.
- `scanning-light.jpg` / `scanning-dark.jpg`: matching 2200×1464 captures of the visible scan banner, current item, discovered count, and Stop Scan control. Debug `--ui-slow-scan` slows fixture events for capture only; these images make no percentage or speed claim.
- `cleanup-light.jpg` / `cleanup-dark.jpg`: existing 2520×1640 Standard Clean captures, with no items selected and no cleanup executed. The controls remain current.

JPEG encoding is used for delivery; no interface, numbers, or labels are redrawn. Keep the visible test-folders label when refreshing captures. Sample sizes and disk availability are not claims about cleaning performance.

The README and website reuse the overview and scanning pairs. GitHub `<picture>` sources follow light/dark appearance. The website also offers Auto, Light, and Dark previews controlling both screenshots; Auto is the initial state. No visitor files are scanned by the website.
