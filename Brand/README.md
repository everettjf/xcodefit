# XcodeFit artwork

Original artwork was made with the built-in ImageGen tool for XcodeFit. Both images have transparent backgrounds. The app icon master is `xcodefit-icon-master.png`; the matching checkup hero is `../web/assets/checkup-mascot.png`. `swift Tools/GenerateIcon.swift` exports the macOS icon size set without altering the master illustration. The web icon is a 512px raster size variant.

## Icon prompt

Use case: logo-brand. Create a polished production macOS app icon for XcodeFit, a friendly Xcode storage checkup and cleanup app. Exactly one adorable chunky claw hammer mascot, centered and very readable at tiny sizes. The hammer itself is the whole character: an oversized pudgy satin steel-blue hammer head, recognizable flat striking face on the LEFT and rounded curved split claw on the RIGHT, two tiny dark friendly eyes and a subtle smile on the broad front surface of the metal head; a very short thick softly rounded warm peach-orange handle as its chubby body, tiny stubby feet. The silhouette should feel huggable and heavyweight, like a collectible designer toy. Premium restrained soft 3D clay rendering, smooth surfaces, gentle highlights, slight three-quarter angle. A small mint medical checkup badge with a simple check mark on the handle, tastefully integrated, no extra props. Square composition, isolated on a genuinely transparent background, complete entire mascot visible with generous 14% clear margins, no rounded-square background tile, no text, no letters, no Apple logo, no Xcode app blueprint icon, no watermark, no comparison or multiple characters. This image will be used directly as the app icon and as a character reference for the website.

## Website hero prompt

Reference: icon master above.

Use case: stylized-concept. Create the website hero character illustration for XcodeFit using the attached cute claw-hammer mascot as the exact character/style reference. Keep the same smiling chunky satin steel-blue claw hammer head, left striking face, right split curved claw, black friendly eyes, warm orange rounded handle/body and tiny feet. This version is a full-body 'Xcode getting a storage checkup' mascot: make its orange body delightfully round and pudgy, with tiny friendly arms and an open rounded mint-and-cream inspection panel on its belly, showing four simple colorful neatly fitted toy-like internal components (a blue cuboid, a mint layered stack, a peach capsule and a violet storage cylinder), suggesting builds, caches, simulators and archives. It is a happy patient receiving a checkup, NOT a doctor wearing a coat. A single loose teal stethoscope loops gently over one shoulder with its round sensor near the inspection panel. Warm sophisticated friendly collectible-toy 3D illustration, soft studio light, clean tactile materials, visually coherent with reference icon, no clutter. Entire character visible, centered, large clear silhouette, generous transparent margins. Isolated on a genuinely transparent background, no text, no letters, no labels, no logos, no medical emergency symbols, no external interface or surrounding cards; the website will add its own live text and interactive cards.
